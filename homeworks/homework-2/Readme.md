## Формат данных

Файл `results.txt` в рабочей папке запуска. Каждая запись — пара `id score`.
`id` — целое от 1 до 9999, `score` — от 0 до 100. Не более 100 записей.
Пары разделяются пробелами или переводами строк.

Пример:
```bash
101 80 205 95 310 60 420 50

## Команды

- `1` — показать все записи
- `2` — статистика
- `3` — поиск по id
- `4` — вариант 2: балл строго больше 80
- `5` — сохранить в `report.txt`
- `0` — выход
```
